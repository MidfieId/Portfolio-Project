# Organizing playlists from YouTube

RemoteTube is a personal full-stack project that brings YouTube playlist information into a focused, easy-to-use interface.

## Build notes

- Built the backend with ASP.NET Core API.
- Developed the responsive interface with React and Tailwind CSS.
- Integrated the YouTube Data API to retrieve and organize playlist data.

## Focus

The project concentrated on clean API integration, an accessible interface, and a smooth experience across screen sizes.
