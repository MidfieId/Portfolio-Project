# Building a real-time chat experience

Ldev Chat was a collaborative project focused on delivering a straightforward, real-time messaging experience. I worked primarily with the frontend team, turning page designs into responsive interfaces and helping connect them to server communication.

## Highlights

- Developed reusable Blazor UI components for the chat experience.
- Collaborated with teammates on interface design and integration.
- Worked with WebSocket-powered real-time communication.

## What I learned

This project strengthened my experience working inside a team codebase and communicating across frontend and backend responsibilities.
