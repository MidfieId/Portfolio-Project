# A portfolio built for clarity

This site is intentionally lightweight: no account system, database, or server is required. Project write-ups live in Markdown, which keeps the content easy to update without changing the page components.

## Structure

- Each project has a small metadata entry in the project registry.
- Long-form details are stored in a dedicated Markdown file.
- A matching asset directory is reserved for screenshots, diagrams, and other project media.
